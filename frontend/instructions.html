Test Instructions

  • The test contains 10 questions.
  • You will have 20 minutes to complete the test.
  • The timer starts as soon as you click "Start Test" and cannot be paused.
  • Marking scheme: +5 for each correct answer, -2 for each incorrect answer, 0 for unattempted questions.
  • Use "Save" to record your answer for each question, and "Clear Options" to remove your selection.
  • Use the bookmark button to flag a question for review before you submit.
  • You can move between questions freely using Previous / Next or the question panel.
  • The test auto-submits when time runs out, or you can submit manually anytime.
  • You are allowed only ONE attempt at this test.
